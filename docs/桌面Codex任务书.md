## 后续集成顺序

1. 核对云端 greeter.h 与 audio_queue.h 的版本，运行可用的主机测试或审查测试证据。
2. 将纯 C core 编入 K210，先确认 LCD 与串口计数。
3. 加入音频，审查读卡、中断回调、末块长度与释放路径。
4. 用真实检测日志回放误计案例，将修复任务交给云端侧。
5. 形成正式发布包，包含固件、音频、SHA256、配置、烧录和验收说明。

用户提供日志后，可以在本聊天直接发送“按计划继续 M1”或“这是 M3 的实测日志，请修复”。开发工作继续按既定任务推进。
