# 侧身识别调优 v0.6

实板 v0.5 侧身通行时，串口连续输出 `persons:[]`。模型仍是课程物体检测模型的 `person` 类，不存在正脸判断；计数器只能处理检测模型给出的人员框。

本版将板端人员检测阈值由 0.50 降至 0.30，短暂漏检保留时间由 350 ms 增至 800 ms。实板当前约 229 ms/帧，新的保留时间允许跨过约三帧的短暂检测空缺。计数仍要求同一人依次跨过 A/B 两线；如果侧身时模型完全不输出人员框，调整阈值也无法保证计数。

风险：较低阈值可能增加误检或多人模糊状态。烧录后需同时验证空画面不误报、正面通行和侧身通行。若侧身仍无青色人员框，需要换用或重新训练覆盖侧身姿态的 K210 人体检测模型，不能通过修改计数规则凭空产生人员框。

## 实板结论（2026-11-13）

用户侧身往返测试后反馈 v0.6 未计数，效果比 v0.5 差。此调参方案判定失败，不作为展示固件。已通过 K-Flash 将板子回退烧录为先前通过进出计数及语音测试的 v0.5；回退后的新一轮通行尚待复核。v0.6 分支仅保留实验记录。
