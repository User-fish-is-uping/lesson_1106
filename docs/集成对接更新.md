## 固件接入注意

人员观测时间使用 observed_ms；语音队列的入队与服务时间使用当前单调时钟采样值，event.timestamp_ms 保留观测时间。不要将旧观测时间作为已推进的队列服务时间，造成时间倒退拒绝。

先将 greeter.c/audio_queue.c 加入固件、静音验证计数，再接播放器。core 只更新一次计数；固件日志和显示读取 snapshot。播放器每主循环最多尝试一次启动；STARTED 后不在结束回调重复消费。

## 日志精度建议

检测版当前使用 `%.5f` 输出坐标与分数。接近 0.50 的分数可能被四舍五入为 0.50000，导致实板已接受的框在回放被过滤；接近线边界的坐标也可能改变区域判断。建议固件对传给 core 的同一组 float 值采用 `%.9g` 输出，保留单精度往返所需精度。请在固件分支处理，不必改变公共接口。
