# K210 双向客流统计与语音迎宾系统

面向商店单通道入口，利用 K210 的 KPU 人员检测结果判断通行方向，统计进入、离开次数，并通过 LCD 与语音提供反馈。

系统采用双线状态机：人员在一侧建立稳定起点，经过中间区域，再到达另一侧稳定终点，才确认一次通行。停留和未完成穿越的折返不增加计数。当前设计支持单人依次通过，多人同时出现时暂停该片段自动计数，待重新建立明确起点后恢复。

```text
摄像头 → KPU 人员检测 → 双线通行判定 → 进出计数
                                      ├→ LCD 与串口日志
                                      └→ 语音事件队列 → I2S 播放
```

## 功能

- 双向通行判定、进入与离开计数、方向反转配置。
- 停留防重复、折返处理、短时漏检保留及异常轨迹重建。
- 固定容量语音队列，支持事件去重、忙时等待、有限重试、过期和静音。
- 确定性主机测试，以及复用 C 状态机的 JSONL 检测日志回放。

## 构建与测试

主机环境需要 C99 编译器、CMake 3.16 及以上版本和 Python 3。

```sh
cmake -S . -B build/host
cmake --build build/host -j2
ctest --test-dir build/host --output-on-failure
python3 tools/host/replay.py tests/data/synthetic_roundtrip.jsonl
```

`core/` 不依赖 SDK 或 Python。Python 用于主机回放与相关测试；示例日志为合成数据。

## 目录

| 路径 | 内容 |
|---|---|
| `core/` | 可移植 C 状态机与语音事件队列 |
| `tests/` | 确定性测试与合成检测数据 |
| `tools/host/` | 主机日志回放与接入示例 |
| `docs/` | 接口规范、构建说明、开发流程及验证记录 |

板端代码位于 `firmware/vision_check/`（共用视觉链路）和 `firmware/vision_count/`（双向计数适配），Windows 构建与测试入口在 `tools/windows/`。TF 卡和 I2S 播放仍待集成。

硬件平台为 Yahboom YB-DKA01 V1.1，使用摄像头、LCD、扬声器和 TF 卡。现有课程模型与驱动需要由固件集成适配。
