# K210 双向客流统计与语音迎宾系统

本目录用于两人协作开发。当前已完成规划、接口约定和人员检测检查版交叉编译；完整迎宾固件与实板验证尚未完成。

统一仓库为 `User-fish-is-uping/lesson_1106`。`main` 是协作资料起点，云端在 `cloud/core` 开发，桌面在 `desktop/firmware` 开发。视觉检查版源码随桌面分支交付。桌面本地统一使用 `D:\Codex\专业基础实践\lesson_1106`；旧 `k210-greeter` 目录保留作准备阶段副本，后续不再双向同步编辑。

项目使用亚博 AI-Motion K210 V1.1 板卡。摄像头和 KPU 检测人员，连续帧位置用于判断进出方向，扬声器分别播放欢迎语和送别语，LCD 显示进出次数与运行状态。

## 阅读顺序

1. 两人先读 [两人开发计划](docs/两人开发计划.md)，理解目标、分工、步骤和验收范围。
2. 两边 Codex 按 [接口约定](docs/接口约定.md) 对接检测结果、计数事件和语音队列。
3. 桌面侧按 [桌面 Codex 任务书](docs/桌面Codex任务书.md) 开始硬件链路开发。同学在其云端可访问的项目仓库中使用 [云端 Codex 任务书](docs/云端Codex任务书.md)。
4. 每轮合并或烧录后填写 [交接与实测记录](docs/交接与实测记录.md)。
5. 首轮人员检测固件见 [视觉检查版使用说明](docs/视觉检查版使用说明.md)，包含编译命令、固件校验和与板上检查步骤。
6. 云端开发前的边界规则补充见 [云端开发理解审阅回复](docs/云端开发理解审阅回复.md)，与接口 v0.2 一起使用。

## 首版交付范围

- 单人依次通过，支持两个方向。
- 完整进入播欢迎语，完整离开播送别语。
- 停留和未完成穿越的折返不增加计数。
- LCD 显示人员框、两条判断线、方向、进出次数和播放状态。
- 播放期间继续检测，语音事件按顺序处理。
- 有串口日志，能够复盘误计、漏计和音频问题。

## 协作入口

桌面 Codex 负责实际板端源码、K210 交叉编译、视觉和音频驱动集成。云端 Codex 负责不依赖板卡的 C 状态机、语音事件队列和主机测试。两边通过共享仓库中的文件与提交记录交接。

云端从共享库的 main 创建 cloud/core，桌面使用 desktop/firmware。交接提供完整提交 SHA 和测试结果。公开头文件由云端维护、桌面审阅。两边不会自动同步聊天，规范和结果须写入仓库。
